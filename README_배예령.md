# 포항 죽도시장 이용 지원 웹서비스

**<a href="https://ax-ton-iota.vercel.app/" target="_blank" rel="noopener noreferrer">🔗 서비스 보러가기</a>**

죽도시장 방문객이 품목별 가격을 비교하고, 매장 정보·후기·동선까지 확인할 수 있는 시장 이용 지원 웹서비스입니다.

---

## 문제

2025년 8월, 포항 남구의 한 횟집이 오징어물회를 '시가'로 표기해 논쟁이 된 지역 뉴스([대경일보](https://www.dkilbo.com/news/articleView.html?idxno=508446))를 보고 문제를 발견했다. 실제로 이 기사에서 경기도에서 온 대학생 관광객은 "바닷가라 비싼 건 이해하지만, 가격을 미리 알 수 없으니 불안하다"고 말했다. 죽도시장도 마찬가지로, 방문객이 가게마다 다른 가격을 미리 비교할 방법이 없다는 문제로 이어진다고 판단했다.

## 해결

- 상인이 가격을 등록할 때 처음에는 로그인 기반 인증을 쓰려 했지만, 개발 기간이 짧고 로그인 서비스 자체가 복잡해서 **PIN 4자리 인증**으로 방식을 바꿨다. 

- 8/18 첫 프로토타입은 검색 → 필터 → 가격목록 3개 화면만 있는 정적 목업이었다.  

  이후 다국어(한/영/일/중) 지원, PIN 인증 가격 등록, 영수증 인증 후기, 동선 안내 지도 등을 추가하며 8/24 v35까지 반복 개선했다.

- 완성된 화면을 직접 써보며 나온 피드백을 순서대로 반영했다. 실제로 고친 것들:
  1. **검색이 안 됨** — "시금치"라고 검색해도 안 나왔던 건 애초에 카탈로그에 없던 품목이라서였음 → 상인이 없는 품목도 직접 등록할 수 있는 "새 품목 만들기" 기능을 추가해 해결
  2. **이모지 제거** — 이모지 아이콘이 "AI가 만든 티가 난다"는 지적을 받아, 품목의 실물 사진으로 교체
  4. **글자 겹침** — 제목 바로 아래 설명문에만 적용하려던 여백 규칙이 다른 요소에도 적용되며 겹쳐 보이던 버그를 수정
  5. **가격 입력란 구분** — 수량 입력칸과 가격 입력칸이 똑같이 생겨 헷갈린다는 지적에, 칸마다 작은 라벨을 붙여 구분
  6. **품목별 가격 단위 차등화** — 시금치 같은 나물류는 3천~1만원대, 대게처럼 비싼 품목은 4만~10만원대로 카테고리·품목별 가격 가이드(placeholder)를 따로 설정
  7. **없는 품목 등록 기능** — 상인이 카탈로그에 없는 품목을 직접 추가하고 바로 가격까지 등록할 수 있게 함
  8. **PIN 입력 후 Enter 키 지원** — 확인 버튼을 누르지 않아도 Enter로 바로 인증되도록 수정

### AI 활용

화면 구성을 담은 PPT와 디자인 시안을 먼저 만들어 Claude Code에 전달하고, 그대로 구현해달라고 요청하는 방식으로 시작했다. 이후에는 완성된 화면을 직접 써보면서 위 8가지처럼 구체적인 문제를 찾아 Claude Code에 다시 수정을 지시하는 것을 반복했다(v11~v35).

## 내가 맡은 일

웹사이트의 첫 화면(초기 틀)을 만들었다.

## 결과

현재 배포된 버전에서 실제로 작동하는 기능:
- 품목 검색 및 매장별 가격 비교 (오늘의 시세판, 가격 변동 표시)
- 한국어/영어/일본어/중국어 4개 언어 지원
- PIN 인증을 통한 상인 본인 가게 가격 등록·수정, 없는 품목 직접 추가
- 영수증 인증 후에만 후기 작성 가능
- 찜한 매장까지의 동선(길찾기) 안내 지도

실제 사용 중 나온 8개 피드백 중 7개를 위와 같이 반영해 재배포했다.
